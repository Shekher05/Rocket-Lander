# Results

Generated by `python -m rocket_land.report` from `runs/<reward>/seed<k>/eval.json`. Do not edit by hand.

## How the numbers were made

- 4 rewards x 3 training seeds = 12 runs. Each run was evaluated on 20 episodes (LunarLander-v3, env seeds 10000 to 10019), deterministic policy, with the plain built-in reward and no reward wrapper. So the score is always the built-in score, even for `hover_hack` and `potential_fix`.
- The `std within run` column is the population std of the 20 episode scores of that one run (as written by `evaluate.py`).
- The `mean ± std` rows use the **sample std (n - 1)** across the 3 seeds, applied to each column (rates are in percentage points). With only 3 seeds this is a rough spread, not a confidence interval.
- landed / crashed / hover / grounded_timeout are the outcome labels of `rocket_land/outcomes.py`. `farming %` = hover % + grounded_timeout % (a run that times out in the air or on the pad). `at 1000-frame limit %` counts episodes that used all 1000 frames, whatever their label. Episodes can be labelled landed and still be very long, so read the mean episode length next to farming.
